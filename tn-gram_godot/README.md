# Тнграм — приложение

Приложение мессенджера «Тнграм» на движке **Godot 4.7** (GDScript, без сторонних библиотек).
Есть интерфейс, хранение переписки **на устройстве** и связь через **сервер-передаточник**,
который держит сообщение ровно до момента, пока его не заберёт получатель.

## Как запустить

Двойной клик по **`start.bat`** — поднимет и сервер-передаточник (в отдельном окне), и приложение,
а ещё напечатает адрес для друзей. Адрес достаточно вписать один раз в `Настройки → Связь` — он
запоминается и переживает перезапуск. Посмотреть адрес, ничего не запуская: **`start.bat info`**.
Если Godot установлен в другом месте, открой файл `.bat` и поправь путь `GODOT_EXE` в первой строке.

Другие способы:

- двойной клик по **`run.bat`** — только приложение, без сервера;
- из редактора Godot: `Project → Open` → выбрать папку `tn-gram_godot` → `F5`;
- **`test.bat`** — автопроверки без окна: сначала интерфейс и данные, потом связь;
- **`relay.bat`** — только сервер-передаточник (держи открытым, пока общаешься);
- **`run_second.bat`** — второе окно приложения со своим профилем (для проверки связи на одном ПК);
- **`firewall.bat`** — открыть входящий порт `7777` в файрволе Windows (спросит права администратора).

## Связь: как проверить прямо сегодня

Ни аккаунтов, ни интернета, ни чужих сервисов не нужно — всё работает на твоём компьютере.

1. Запусти **`relay.bat`** — консоль напишет, что сервер слушает порт `7777`. Оставь её открытой.
2. Запусти **`run.bat`**, войди как `админ`.
3. Запусти **`run_second.bat`** — откроется второе окно со своим профилем, войди как `админ2`.
4. В каждом окне: `Настройки → Связь → адрес 127.0.0.1:7777 → Подключиться`.
   Если включишь галочку «Подключаться при входе», вставать на связь будет само.
5. Напиши что-нибудь из одного окна — сообщение появится в другом.

Что происходит в это время: сообщение сохраняется у тебя, уходит на сервер, сервер держит его и
отдаёт получателю, получатель подтверждает — и сервер **сразу удаляет** у себя. Если получатель
оффлайн, сообщение подождёт на сервере и пришлётся, как только он выйдет на связь.

Для людей в той же домашней сети подключайся не к `127.0.0.1`, а к адресу этого компьютера —
`start.bat` печатает его готовым. Windows при первом запуске может спросить «разрешить доступ» —
согласись, иначе порт будет закрыт (то же самое делает `firewall.bat`).

## Как проверить с другом из другого города

Прямого выхода в интернет у сервера пока нет — он виден только в своей сети. Рабочих путей два:

1. **Tailscale** — поставь Tailscale себе и другу, войдите под одним аккаунтом. `start.bat` сам
   напечатает адрес вида `ws://100.x.y.z:7777`; продиктуй его другу, он впишет его в
   `Настройки → Связь`. Канал Tailscale сам прокладывается через интернет, роутер настраивать не надо.
2. **Проброс порта** — если провайдер даёт «белый» IP: в роутере пробрось TCP `7777` на этот
   компьютер, открой порт в файрволе (`firewall.bat`) и продиктуй другу внешний адрес. При «сером»
   IP (за NAT провайдера) так не получится.

Облако (Supabase) уберёт оба этих шага — это следующий шаг.

## Что уже работает

- **Вход без номера телефона.** Аккаунт — это ник. Телефон и почта не спрашиваются.
- **Два готовых аккаунта при первом запуске:** `админ` и `админ2`, оба без пароля.
- **Создание ника** с паролем по желанию (пароль хранится не в открытом виде, а хешем).
- **Список чатов** — аккаунты этого устройства и те, с кем уже переписывался по сети.
- **Переписка:** пузыри сообщений (свои — сине-зелёные справа, собеседника — слева), время, удаление переписки.
- **Связь:** адрес сервера в настройках, кнопка «Подключиться», состояние связи видно на экране чатов
  и под полем ввода; есть «подключаться при входе».
- **Доставка с удалением:** сервер держит сообщение до подтверждения и удаляет его;
  неотданное ждёт получателя, повторная доставка не создаёт дублей.
- **Темы:** тёмная, зелёная, синяя — перекрашивают приложение целиком.
- **Язык:** русский и английский, переключатель на экране входа и в настройках.
- **Сохранение:** вся переписка и аккаунты лежат в файле на устройстве и переживают перезапуск.

## Чего ещё нет (честно)

- **Пока это связь в пределах одного компьютера, одной сети или сети Tailscale.** Внешний адрес и облако — следующий шаг.
- **Сервер ничего не запоминает после перезапуска.** Недоставленные сообщения лежат в памяти:
  если закрыть `relay.bat`, они пропадут. Файловое хранение на сервере сделаем потом.
- **Пароль аккаунта не защищает сообщения.** Сервер (и тот, кто им владеет) видит текст сообщения
  и то, кому оно отправлено. Полное шифрование — отдельная и большая задача.
- **Регистрации нет:** ника достаточно, и два человека могут назвать себя одинаково.
  Первый, кто подключится, может занять чужой ник — сейчас сервер отдаёт ник последнему подключившемуся.
- **Восстановления нет.** Переписка живёт только на устройстве: если файл данных удалится, вернуть её нельзя.
- Уведомлений, отправки файлов, звонков — нет.

## Автопроверки

- **`test.bat`** — обе проверки сразу, окно не нужно.
  Интерфейс и данные: **110 проверок** (аккаунты, вход, пароли, приём сообщения из сети, настройки связи,
  язык, темы, раскладка, окна подтверждения, нажатия кнопок как у человека, а в конце — сквозная
  проверка: настоящее приложение разговаривает с настоящим сервером и сообщение ходит в обе стороны).
  Связь: **21 проверка** (доставка, оффлайн-очередь, удаление после подтверждения,
  отказ без сервера, вытеснение повторного входа под тем же ником).
  **Внимание: проверка сбрасывает данные приложения** и в конце оставляет чистый старт.
  Отчёты: `%APPDATA%\Godot\app_userdata\TNGram\smoke_report.txt` и `…\net_report.txt`.

## Где что менять

- **Тексты** — `scripts/Loc.gd`, словарь `STRINGS` (разделы `ru` и `en`).
- **Цвета и темы** — `scripts/Style.gd`, словарь `PALETTES` (`dark`, `green`, `blue`).
- **Готовые аккаунты** — `scripts/Store.gd`, строка `DEFAULT_ACCOUNTS`.
- **Пороги связи** — `scripts/net/TnNet.gd` (`CONNECT_TIMEOUT`) и `relay/RelayServer.gd` (`RESEND_EVERY`).
- **Название и размер окна** — `project.godot`, разделы `[application]` и `[display]`.
- **Новый экран** — добавь файл в `scripts/ui/`, затем впиши его в словарь `SCREENS` в `scripts/Main.gd`.

## Где лежат данные и как всё сбросить

```
%APPDATA%\Godot\app_userdata\TNGram\tngram_data.json
```

Удали этот файл — приложение начнётся с чистого листа (снова появятся `админ` и `админ2` без паролей).

У второго окна, запущенного через `run_second.bat`, свой файл: `tngram_data_second.json`.

## Как получить .exe

Нужны шаблоны экспорта Godot: в редакторе `Editor → Manage Export Templates → Download and Install`
(около 800 МБ). После этого `Project → Export → Windows Desktop`.

Шаблоны пока не установлены, поэтому файла `.exe` ещё нет. Настройки экспорта (`export_presets.cfg`)
тоже пока не создавались — сделаем, когда понадобится.
