# Тнграм — сайт

Одностраничный информационный сайт мессенджера Тнграм (Tngram).
Без серверов, без базы данных, без сборки: один файл `index.html` со встроенными CSS и JS.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Весь сайт: разметка + стили + скрипты |
| `icon.png` | Иконка приложения (логотип, favicon) |

Открывается двойным кликом по `index.html` — работает сразу, интернет не нужен.

## Что есть на странице

Шапка с переключателем RU / EN · главный экран со слоганом и плашкой «Скоро» ·
«Что это» · 5 карточек возможностей · платформы (Android, Windows 11, Linux, веб) ·
«Как это работает» (3 шага с подсветкой при скролле + таблица сравнения с обычным
мессенджером) · мокап приложения (сообщение уходит на сервер и удаляется, в чате
остаётся) · темы оформления (клик меняет цвета сайта) · «Чего мы не собираем» ·
FAQ на 6 вопросов · статус и дорожная карта · подписка на новости · подвал.

## Как поменять контент

- **Все тексты (RU и EN)** — объект `TEXTS` в `<script>` внизу `index.html`.
  Меняй `TEXTS.ru.*` и `TEXTS.en.*` — разметку трогать не нужно.
- **Цвета, скругления, размытие** — вверху `<style>`, блок `:root`.
- **Темы оформления** — там же: `--a1` / `--a2` у `[data-theme="green"]` и `[data-theme="blue"]`
  (значения записываются как `47,123,255`, без `rgb()`).
- **Настройки** (в самом начале `<script>`, объект `CONFIG`):
  - `contactEmail` — куда придёт письмо, если форма подписки не подключена.
  - `links.telegram` / `links.github` — вставь ссылки, кнопки включатся сами.
    Пустая ссылка = кнопка скрыта.
  - `subscribersCount` — счётчик «Нас уже N». Показывается, **только если указать
    реальное число**. По умолчанию `null` — счётчика нет.
  - `subscribeEndpoint` — ссылка бесплатного сервиса форм (например
    [Formspree](https://formspree.io) или [Getform](https://getform.io)).
    Пока пусто — кнопка «Подписаться» открывает почтовый клиент с готовым письмом.
- **Иконка** — просто замени файл `icon.png` своим (квадратный, от 256×256).
- **Язык и тема по умолчанию** — `TEXTS` / атрибут `data-theme` у `<html>`.
  Выбор пользователя запоминается в браузере.

## Бесплатный хостинг (без сервера и без оплаты)

Вариант 1 — **GitHub Pages** (рекомендую):
1. Залей проект на GitHub.
2. Settings → Pages → Source: **GitHub Actions**.
3. Готово. Файл `.github/workflows/pages.yml` уже в проекте — сайт будет
   обновляться сам при каждом `push`.
4. Адрес будет вида `https://<твой-логин>.github.io/TNGram/`.

Вариант 2 — **перетащить папку** (совсем без git):
- [Netlify Drop](https://app.netlify.com/drop) — перетащи папку `сайт`, ссылка появится сразу.
- [Cloudflare Pages](https://pages.cloudflare.com/) — то же самое.

## Свой домен позже

Домен подключается в настройках хостинга, бесплатно:
- GitHub Pages: Settings → Pages → Custom domain.
- Netlify / Cloudflare Pages: Domain settings → Add custom domain.

Достаточно купить домен и прописать DNS-записи, которые предложит хостинг.
Сайт при этом менять не нужно.
