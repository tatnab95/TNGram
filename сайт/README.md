# Тнграм — сайт

Одностраничный информационный сайт мессенджера Тнграм (Tngram).
Без серверов, без базы данных, без сборки: один файл `index.html` со встроенными CSS и JS.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Весь сайт: разметка + стили + скрипты |
| `icon.png` | Иконка приложения (логотип, favicon) |
| `TNGram.apk` | Сборка для Android (кнопка «Скачать») |
| `TNGram-win64.zip` | Сборка для Windows, архив (кнопка «Скачать») |
| `TNGram.x86_64` | Сборка для Linux (кнопка «Скачать») |

Открывается двойным кликом по `index.html` — работает сразу, интернет не нужен.

## Что есть на странице

Шапка с переключателем RU / EN · главный экран со слоганом и плашкой версии ·
«Что это» · 5 карточек возможностей · платформы (Android, Windows 11, Linux, веб) ·
«Как это работает» (3 шага с подсветкой при скролле + таблица сравнения с обычным
мессенджером) · мокап приложения (сообщение уходит на сервер и удаляется, в чате
остаётся; в поле можно печатать самому — это демо, ничего не отправляется) ·
темы оформления (клик меняет цвета сайта) · «Чего мы не собираем» ·
FAQ на 6 вопросов · статус и дорожная карта · опрос из 5 вопросов с процентами ·
открытый код (ссылка на GitHub) · подвал.

## Опрос на 5 вопросов

Секция `#survey`. Вопросы и варианты лежат в `TEXTS.ru.survey.questions` /
`TEXTS.en.survey.questions`, у варианта с флагом `free: true` появляется поле
«свой вариант». Четвёртый вопрос помечен `multi: true` — не больше двух ответов.

Куда деваются ответы:

1. **В браузере** — всегда: `localStorage` под ключом `tngram-survey-votes`.
   Проценты по этим ответам видны сразу.
2. **В облако Supabase** — если выполнены два условия: в `CONFIG.survey` включён
   `enabled: true`, а в проекте Supabase выполнен файл `supabase/Опрос.sql`
   (SQL Editor → New query → Run). Он создаёт таблицу `survey_votes` и сводку
   `survey_tally`. Пока таблицы нет — сайт молча показывает локальные проценты,
   ничего не ломается.

Посмотреть результаты: Supabase → Table Editor → `survey_votes`, или запрос
`select * from public.survey_tally order by q, votes desc;`.
Проценты сайт считает сам: `votes / сумма votes по этому вопросу`.

При открытии сайта наверху появляется маленькое окно «Пройдите, пожалуйста,
короткий тест»: кнопка плавно прокручивает страницу к опросу, крестик закрывает
окно, а при прокрутке страницы оно скрывается само. Тексты — `TEXTS.*.welcome`.

## Сборки приложений

- Android — `TNGram.apk`, лежит прямо в папке сайта.
- Windows — в карточке две ссылки:
  - «Установщик EXE» ведёт на [GitHub Releases](https://github.com/tatnab95/TNGram/releases)
    (там лежит `TNGram.exe` — сам файл весит ~105 МБ, а GitHub не принимает
    файлы больше 100 МБ, поэтому в репозиторий он не кладётся);
  - «Архив ZIP» — локальный `TNGram-win64.zip` (~37 МБ), если Releases недоступны.
- Linux — `TNGram.x86_64`, лежит в папке сайта. После скачивания нужно
  разрешить запуск: `chmod +x TNGram.x86_64`.

## Как поменять контент

- **Все тексты (RU и EN)** — объект `TEXTS` в `<script>` внизу `index.html`.
  Меняй `TEXTS.ru.*` и `TEXTS.en.*` — разметку трогать не нужно.
- **Цвета, скругления, размытие** — вверху `<style>`, блок `:root`.
- **Темы оформления** — там же: `--a1` / `--a2` у `[data-theme="green"]` и `[data-theme="blue"]`
  (значения записываются как `47,123,255`, без `rgb()`).
- **Настройки** (в самом начале `<script>`, объект `CONFIG`):
  - `links.github` — ссылка на репозиторий (по умолчанию `https://github.com/tatnab95/TNGram`).
    `links.telegram` — канала пока нет, пустая ссылка = кнопка скрыта.
  - `survey.url` / `survey.key` / `survey.table` / `survey.tally` — облако Supabase
    для ответов опроса. Ключ `sb_publishable_…` публичный, он не секрет.
    `survey.enabled: false` — отключить отправку в облако (локальные проценты останутся).
- **Иконка** — просто замени файл `icon.png` своим (квадратный, от 256×256).
- **Язык и тема по умолчанию** — `TEXTS` / атрибут `data-theme` у `<html>`.
  Выбор пользователя запоминается в браузере.

## Бесплатный хостинг (без сервера и без оплаты)

Вариант 1 — **GitHub Pages** (рекомендую):
1. Залей проект на GitHub.
2. Settings → Pages → Source: **GitHub Actions**.
3. Готово. Файл `.github/workflows/pages.yml` уже в проекте — сайт будет
   обновляться сам при каждом `push`.
4. Адрес будет вида `https://<твой-логин>.github.io/TNGram/`.

Вариант 2 — **перетащить папку** (совсем без git):
- [Netlify Drop](https://app.netlify.com/drop) — перетащи папку `сайт`, ссылка появится сразу.
- [Cloudflare Pages](https://pages.cloudflare.com/) — то же самое.

## Свой домен позже

Домен подключается в настройках хостинга, бесплатно:
- GitHub Pages: Settings → Pages → Custom domain.
- Netlify / Cloudflare Pages: Domain settings → Add custom domain.

Достаточно купить домен и прописать DNS-записи, которые предложит хостинг.
Сайт при этом менять не нужно.
